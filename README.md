# Enterprise Site-to-Site VPN & Redundant Gateway Topology

Проект построения корпоративной сетевой инфраструктуры с резервированием каналов и узлов распределения в Cisco Packet Tracer.

---

## 1. Архитектура сети

- **Центральный офис (HQ):**
  - Отказоустойчивый шлюз на базе протокола **HSRP v1** (`192.168.1.1`): `R0-HQ` (Active, приоритет 110), `R1-HQ` (Standby, приоритет 100) во VLAN 10.
  - Локальная L2-инфраструктура: агрегированный отказоустойчивый транк **EtherChannel (Layer 2)** между коммутаторами `S0` (Fa0/3-4) и `S2` (Fa0/1-2). Пользовательские порты переведены в режим Access VLAN 10 с оптимизацией Spanning-Tree PortFast.
  - Локальный сервис адресации: пул **DHCP** на `R0-HQ` для подсети `192.168.1.0/24`.
- **Филиал (Branch):**
  - Маршрутизатор `R4-BRANCH` с локальным пулом DHCP для подсети `192.168.2.0/24`.
- **Транзитная сеть (ISP-CORE):**
  - L3-маршрутизация между внешними адресами штаба (`203.0.113.0/30`, `203.0.113.4/30`), филиала (`198.51.100.0/30`) и DNS/Web-сервером (`8.8.8.8`).
- **Связь между площадками (VPN):**
  - Защищенный туннель **GRE over IPsec** между `R0-HQ` и `R4-BRANCH` (`Tunnel0`, сеть `10.255.255.0/30`).
  - Параметры криптографии: IKE Phase 1 (AES-128, SHA-1, DH Group 2, PSK), Phase 2 (ESP-AES, ESP-SHA-HMAC).

## 3. Статус верификации

- **EtherChannel:** Агрегированный порт-канал `Po1(SU)`, физические интерфейсы в статусе `(P)`.
- **HSRP:** Маршрутизатор `R0-HQ` удерживает виртуальный IP `192.168.1.1` в режиме Active.
- **IPsec SA:** Состояние фазы IKE — `QM_IDLE`, криптокарта активна.
- **Связность:** Сквозной пинг между хостами филиала и штаба через туннель проходит со 100% успехом.
